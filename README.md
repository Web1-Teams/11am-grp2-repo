# 11am-grp2-repo
Project Title: Afaq
Description:

Our project is a tourist guide for the cities of the West Bank.
It helps tourists explore the most beautiful and stunning places in the West Bank.
The goal is to enhance the tourism sector in the West Bank by simplifying the discovery and visits to tourist attractions.
Our website opens up horizons for you to explore the West Bank.
It guides you to hotels, restaurants, and tourist sites to ensure the best experience for tourists.
Features:

    Responsive Design: Works on all devices (phones, tablets, computers).
    Login System: Allows users to log in using email.
    High Interactivity: Buttons and tools are easy to use.
    Data Management: Add, edit, and delete data easily.
